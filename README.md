# Power BI — Módulo 6 | Atualizando Relatório Financeiro com Foco na Experiência do Usuário

Projeto organizado a partir do **Desafio de Projeto - Módulo 6** e do arquivo PBIX fornecido no curso.

> **Objetivo:** centralizar neste README os arquivos do projeto, a documentação da análise, os recursos visuais extraídos do PBIX e o plano de implementação. Os links abaixo usam caminhos relativos para facilitar a navegação diretamente pelo GitHub.

---

## 🎯 Objetivo do projeto

O desafio solicita a atualização do relatório financeiro com foco na **experiência do usuário**, levando em consideração posicionamento, contraste, proporção áurea e segmentação dos dados.

Também são considerados recursos de **navegação por botões**, evolução da segunda página, estados visuais dos botões, menus de navegação e um relatório final composto por **3 páginas**.

# 📊 Estado atual do PBIX

O arquivo original possui duas páginas reais:

- **Home page**
- **Principal**

A página **Principal** contém gráficos de segmento, período, produto e país, cartões de indicadores, segmentação e botões vinculados a bookmarks.

Entre os bookmarks identificados estão:

- `Gráfico Pie`
- `Gráfico Barra`
- `Gráfico Tremap`
- `Gráfico Map`
- `Clean data`
- `Home page`
- `Distribuição por semestre`
- `Distribuição por meses`

Os cartões identificados utilizam, entre outros indicadores, **Total de Vendas, Unidades Vendidas, Discounts e COGS**.

# 🧭 Plano para finalizar a entrega

## Página 1 — Home page

Manter como capa/entrada do relatório e criar um menu claro para acesso às demais páginas.

## Página 2 — Visão geral financeira

Aproveitar a página Principal existente, revisando:

- hierarquia dos elementos;
- espaçamento;
- contraste;
- estados dos botões;
- segmentação;
- alinhamento dos visuais;
- consistência da identidade visual.

## Página 3 — Detalhamento

Criar uma página de análise complementar mantendo a identidade visual das páginas anteriores.

Uma composição possível é concentrar a análise detalhada de vendas por:

- produto;
- país;
- segmento;
- período;
- descrição de vendas em formato de matriz.

## 🚀 Como usar este projeto

1. Clone ou baixe este repositório.
2. Consulte primeiro o [documento do desafio](original/Desafio%20de%20Projeto%20-%20M%C3%B3dulo%206.docx).
3. Leia a [auditoria do PBIX](documentacao/auditoria_pbix.md).
4. Consulte o [plano de implementação](documentacao/plano_de_implementacao.md).
5. Abra o [arquivo PBIX](original/Desafio%20de%20Projeto%20-%20M%C3%B3dulo%206%20-%20Sales%20Report.pbix) no Power BI Desktop.
6. Utilize os recursos disponíveis em [`recursos/`](recursos/) durante a edição do relatório.
7. Após concluir as alterações, salve a versão final do `.pbix` e atualize este README se novos recursos forem adicionados.
