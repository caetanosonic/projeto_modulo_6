# Power BI — Módulo 6 | Atualizando Relatório Financeiro com Foco na Experiência do Usuário

Projeto-base organizado a partir do **Desafio de Projeto - Módulo 6** e do arquivo PBIX fornecido no curso.

## Objetivo

O desafio solicita a atualização do relatório financeiro com foco na **experiência do usuário**, levando em consideração posicionamento, contraste, proporção áurea e segmentação dos dados. Também solicita navegação por botões, evolução da segunda página e um relatório final composto por **3 páginas**.

## Estado atual do PBIX

O arquivo original já possui duas páginas reais: **Home page** e **Principal**. A página Principal contém gráficos de segmento, período, produto e país, cartões de indicadores, segmentação e botões vinculados a bookmarks.

Há bookmarks para alternância de gráficos, incluindo opções de **Gráfico Pie, Gráfico Barra, Gráfico Tremap e Gráfico Map**, além de navegação.

## Plano para finalizar a entrega

### Página 1 — Home page
Manter como capa/entrada do relatório e criar um menu claro para acesso às demais páginas.

### Página 2 — Visão geral financeira
Aproveitar a página Principal existente, mas revisar a hierarquia dos elementos, espaçamento, contraste, estados dos botões e segmentação.

### Página 3 — Detalhamento
Criar uma página de análise complementar, mantendo a identidade visual da página 1/2. Uma sugestão compatível com o desafio é concentrar a análise detalhada de vendas por produto, país, segmento e período.
